# Internal-Security-Logs-Analysis
Finding data exfiltration in 20 days of logs using network traffic investigation, threat detection, and evidence-based reporting
<hr />

# Summary

This lab involved investigating potentially malicious activity within a simulated enterprise environment using authentication records, firewall logs, and an asset inventory. The objective was to identify the suspicious behavior **hidden** inside the logs, **distinguish** it from legitimate administrative or operational activity, correlate events across available data sources, and document conclusions without overstating the evidence.

For your curiosity, the logs I used are available for viewing and download on this repository. Feel free to try this challenge out yourself!
